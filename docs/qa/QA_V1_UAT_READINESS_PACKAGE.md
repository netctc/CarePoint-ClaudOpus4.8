# QA-V1 UAT Readiness Package

## UAT roles

| Role | Focus |
| --- | --- |
| Admin stakeholder | Accounts, audit, reports, configuration, governance visibility |
| Provider stakeholder | Clinical queue, calendar, prescriptions, encounter notes, dashboard clarity |
| Operator or staff reviewer | Daily workflow usability, routing, evidence, handoff clarity |
| Auditor or reviewer | Traceability, logs, report evidence, access boundaries |

## UAT package contents

- Role-based scenario checklist.
- Acceptance criteria per role.
- Evidence capture instructions.
- Feedback severity model.
- Final signoff template.

## Severity model

| Severity | Meaning | Release impact |
| --- | --- | --- |
| Blocker | Prevents core workflow or safe use | Must fix before go-live |
| High | Material workflow, data, or access issue | Must fix or formally waive |
| Medium | Usability or workflow friction | Triage before go-live |
| Low | Cosmetic or enhancement | Can move to post-go-live backlog |

## Signoff requirement

UAT should not be marked complete until Admin and Provider stakeholders have signed acceptance or formally documented exceptions.
