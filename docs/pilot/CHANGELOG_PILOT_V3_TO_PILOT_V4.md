# Changelog - PILOT-V3 to PILOT-V4

## Added

- Pilot monitoring and support governance scanner.
- Daily health review plan report.
- Incident triage and support model documentation.
- Monitoring/support audit report.
- `npm run audit:pilot:monitoring-support` command.

## Updated

- `npm run audit:pilot` now executes PILOT-V1 through PILOT-V4 audits.
- `docs/pilot/PILOT_PHASE_MANIFEST.json` now marks PILOT-V4 as current and PILOT-V3 as completed.

## Not changed

- Backend contracts.
- Python worker.
- Database schema.
- Application runtime logic.
- QA-V7 closure state.
