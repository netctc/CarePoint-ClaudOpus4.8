# Changelog UX-V3 to UX-V4

## Added

- Shared responsive/accessibility CSS primitives.
- Responsive and accessibility audit script.
- UX-V4 validation artifact.
- Touch target, focus, reduced-motion, forced-colors, mobile, and print QA coverage.

- Aggregate `npm run audit:ux` now includes UX-V4 audit.
- Design tokens moved from `ux-v3` to `ux-v4`.
- Admin and Provider global CSS include UX-V4 hardening rules.
- Design-system README and phase roadmap updated.

- Python worker.
- Database schema.
- API semantics.
- Closed V64 technical phase status.
