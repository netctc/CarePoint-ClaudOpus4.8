# UX Post-Close Backlog

This backlog is intentionally separated from the closed UX phase. These items are not blockers for UX-V6 closure.

## Recommended future items

1. Add browser-driven visual regression screenshots once the project test runner is standardized.
2. Add automated WCAG contrast tooling to supplement the current source-level smoke checks.
3. Create page-level usability walkthroughs with clinical users.
4. Prioritize any stakeholder-requested visual fine-tuning after signoff.
5. Evaluate a Storybook or component catalog for the design-system primitives.
6. Add mobile-specific acceptance examples for queue, calendar, prescription, audit, and reports surfaces.

## Governance rule

Do not reopen the closed UX-V6 phase for non-blocking improvements. Track them here or open a new design/product experience phase.
