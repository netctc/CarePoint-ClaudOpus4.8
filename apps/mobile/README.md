# CarePoint Flutter Starter

This starter includes source-level Flutter pages for the first 40 patient screens in the CarePoint mobile app flow.

## Included screens

### P-01 to P-04
- Splash & Language Selection
- Welcome / Sign In
- OTP Verification
- Profile Setup

### P-05 to P-08
- Consent Center
- Home Dashboard
- Search Providers
- Filter & Sort

### P-09 to P-12
- Provider Profile Overview
- Provider Reviews
- Select Service
- Select Facility / Location

### P-13 to P-17
- Select Slot
- Appointment Intake Form
- Insurance / ID Upload
- Review & Payment
- Booking Confirmation

### P-18 to P-22
- Upcoming Appointments
- Appointment Detail
- Telehealth Waiting Room
- In-Call Telehealth
- Post-Visit Summary

### P-23 to P-30
- Messages Inbox
- Conversation Thread
- Medical Records Hub
- Document Detail
- Lab Results List
- Lab Result Detail / Trends
- Prescriptions List
- Prescription Detail / Refill

### P-31 to P-40
- Care Plan Overview
- Task Detail / Progress
- Medication Reminders
- Device & Monitoring Setup
- Vitals & RPM Trends
- Wallet & Payment Methods
- Invoices / Refunds
- Family Profiles & Dependents
- Notifications Center
- Support & Complaints

## Notes

- This is a source starter intended to accelerate development.
- Flutter SDK is required to run and build the project.
- API integration, state management expansion, validation, localization files, and production services still need to be implemented.
