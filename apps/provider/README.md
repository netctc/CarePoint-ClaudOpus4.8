# Provider Web Starter

Source-level Next.js starter for the provider-facing web portal.

## Included screens
- PR-01 Provider Sign-In
- PR-02 Onboarding & Verification
- PR-03 Provider Dashboard
- PR-04 Calendar & Availability
- PR-05 Slot Template Editor
- PR-06 Appointment Queue
- PR-07 Appointment Detail
- PR-08 Patient Chart Summary
- PR-09 Telehealth Waiting Room
- PR-10 Live Consultation Console
- PR-11 Encounter Note Editor
- PR-12 Orders & Referrals
- PR-13 Prescription Composer
- PR-14 Lab Orders Inbox
- PR-15 Results Review
- PR-16 Secure Messaging Inbox
- PR-17 Conversation / Care Coordination
- PR-18 RPM Program Panel
- PR-19 RPM Patient Detail
- PR-20 Alerts & Escalations
- PR-21 Billing & Payouts
- PR-22 Performance Analytics
- PR-23 Team & Roles
- PR-24 Facility / Services Settings
- PR-25 Compliance & Audit View

## Included foundation pieces
- Shared portal shell with sidebar and top bar
- Permissions utilities with roles and access helpers
- Mock API service with dashboard, queue, calendar, onboarding, chart, telehealth, labs, RPM, alerts, notes, orders, prescriptions, messaging, billing, analytics, team, settings, and compliance data
- Global design tokens in CSS
